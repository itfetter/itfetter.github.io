新增或修改文章

  1. 点击上方按钮，登录 GitHub 并打开 posts.js。
  2. 修改已有文章，或复制一个 posts 数组中的对象新增文章。为新文章设置不重复的英文 id，填写标题、分类、日期、摘要和正文 HTML。
  3. 点击 GitHub 的 Commit changes 保存。提交到 main 后等待 Pages 发布，再到博客首页检查列表、搜索和文章阅读。

新增分类还需修改 index.html 的筛选按钮；首页置顶文章目前固定指向 hello。详情见仓库的 README 与 AGENTS.md。
