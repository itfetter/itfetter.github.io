文章管理入口

当前入口会跳转到 GitHub 的文件编辑器；站内提供写作与预览页面，发布仍由 GitHub 完成。文章修改与发布由 GitHub 账号和仓库写入权限控制，本页面不接收密码或令牌。

使用 GitHub 管理文章

使用拥有 itfetter/itfetter.github.io 写入权限的 GitHub 账号登录。每篇文章都是 _posts/ 下的独立 Markdown 文件。

新增或修改文章

  1. 先登录 GitHub。修改文章可点击下方对应文章的“编辑”；新增文章可点击“新增文章”进入写作页。
  2. 在写作页填写标题、分类、摘要和英文网址短名，编写正文并预览；页面会生成带唯一 blog_id 和文件名的完整 Markdown。
  3. 复制或下载 Markdown，到 GitHub 新建或上传文件，点击 Commit changes 保存。提交到 main 后等待 Pages 发布，再到博客首页检查列表、搜索和文章阅读。

分类按钮会从文章自动生成；首页置顶卡片目前固定指向 hello，更换置顶需修改 index.html。详情见仓库 README 与 AGENTS.md。
