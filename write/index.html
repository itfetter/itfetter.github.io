生成并发布

本站是静态页面，不读取 GitHub 密码，也不自动写入仓库。请先检查文章信息，再通过 GitHub 提交文件。

去 GitHub 新建文章 ↗

发布前请看：点击“复制”，再打开 GitHub 的新建文章页面；把上方文件名填到文件名输入框，粘贴内容，最后点 Commit changes。或者把下载的文件上传到 _posts/。
  1. 有图片时先到 GitHub 的 assets 上传入口 ↗上传图片并提交；回来点“图片”，输入该图片的真实文件名。图片不会跟随本页的 Markdown 文件一起上传。
  2. 图片写法：![图片说明](/assets/图片名.jpg)。文件名大小写必须一致。
  3. 提交到 main 后等待 Pages 自动部署，再检查首页和文章页。
